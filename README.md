# Walmart-Weekly-Sales-Forecasting-System
Walmart Weekly Sales Forecasting System
Analyzed 143 weeks of sales data across 45 stores, uncovering strong holiday-driven seasonality while confirming that temperature, fuel price, CPI, and unemployment collectively explain <3% of sales variability.
Built ARIMA, SARIMA, and Prophet models on aggregated weekly sales, with Prophet reducing forecasting error (MAPE) by 24% compared to a moving-average baseline.
Visualized store-wise, seasonal, and event-driven demand patterns using Matplotlib and Seaborn, revealing holiday spikes and store variability relevant for inventory and staffing decisions.
